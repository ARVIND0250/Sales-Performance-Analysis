# Sales Performance Analysis

## Project Overview

This project analyzes 500 sales transactions using Microsoft Excel to evaluate sales, profit, regional performance, product performance, salesperson contribution, and monthly trends.

An interactive Excel dashboard is created using PivotTables, PivotCharts, KPI cards, and slicers to transform raw sales data into meaningful business insights.
